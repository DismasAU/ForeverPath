11Layout and ImplementationWhat resizes, what scrolls, what to simplify in Lua
Layout
Header · fixed heightDrag to move · search shrinks first
SidebarFixed width
Content · scrollsPanels reflow · tables gain width
rows keep fixed height
Status bar · fixed
◆Resizable from the corner grip, 820 × 560 to 1400 × 960; size and position saved per character.
◆Scrolling regions: goal list, material tables, dependency tree, shopping list, quest chain.
◆Tracker: fixed 262 px width, grows to six rows, collapses to its 22 px header.
Implementation notes
Tree connector linesOne 1 px texture per guide column, positioned from a precomputed depth list. Fallback: plain indentation with an elbow glyph.
Long tables and treesVirtualised rows in a ScrollBox (FauxScrollFrame on older clients); expand/collapse rebuilds the flat row list.
Icon tiles in these mockupsPlaceholders. Use real item icons from GetItemIcon with the standard quality border.
Bevels and gradientsA single 9-slice backdrop and one tiled stone texture; skip per-panel gradients.
PricesOnly from the player’s own Auction House scans, saved with a timestamp. Never labelled live.
Alt inventoriesSnapshot bags and bank on logout to account-wide saved variables; always show snapshot age.
Tooltips and coinsGameTooltip with SetHyperlink plus added source lines; GetCoinTextureString for amounts.
Item-link inputEditBox that accepts shift-clicked item links to create goals.
FontsBundle the fonts with the addon, or fall back to the client’s default UI fonts.
No automationForeverPath suggests; buying, crafting and mailing stay manual player actions.
API names refer to current WoW clients; confirm availability on World of Warcraft: Forever.
